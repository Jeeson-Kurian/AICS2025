# Exploring AI & Cybersecurity at the University of Klagenfurt

This repository contains the event website for 5 June 2025. The page includes the speaker programme, schedule and venue.

## Preview the site locally

From the repository root, start a static file server and open <http://localhost:8000>. The page loads its styles, scripts and videos from the adjacent directories.

```sh
python -m http.server 8000 --bind 127.0.0.1
```
